I don't really think I have anything salient or new to add to the debate about this being held [here](http://www.buzzmachine.com/2007/04/09/no-twinkie-badges-here/), [here](http://avc.blogs.com/a_vc/2007/04/i_cant_believe_.html), [here](http://www.calacanis.com/2007/04/10/blogger-code-of-conduct/), [here](http://blog.pjsattic.com/corvus/2007/04/free-speech/), [here](http://radar.oreilly.com/archives/2007/04/draft_bloggers_1.html), and [here](http://www.intuitive.com/blog/never_sign_up_for_blogger_code_of_conduct.html).

But I like to think that my opinion matters and that other people want to know it. So I think that the code of conduct is a bad idea. I think that getting your SSN and other personal info posted by angry, anonymous, mobsters is a shitty thing, but,

a) everybody has the right to run their blog the way they want to, and  
b) that crowd won't listen to a code of conduct anyway
