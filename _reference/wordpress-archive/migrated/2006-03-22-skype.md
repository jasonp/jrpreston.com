I've had Skype for a while now, but I've never really had an opportunity to use it much since practically eveyone I know is on AIM.

I like AIM - it's a great service, and it beats the hell out of Skype for simple text messaging. But AOL is so confused with its service, putting out weird clients, hijacking buddy lists, and refusing to open up the network that it forces me to use gaim.

Gaim is great but I can't do voice chat, and sending files is usually buggy. Skype is great for that. The voice chat is amazing and the file send utility works flawlessly.

Also, Skype is starting to get integrated with mobile phones, and most pocket PC devices now being released can have Skype on them, which means that Skype can be used in place of traditional phone service if there's a wireless network around. That's pretty cool.

So I recommend it.
