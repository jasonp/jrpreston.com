I'm not much for tracking my web browsing habits. I think i'm scared to find out what sites I spend the most time on.

But there are two bits of data that I've realized I do want to know. First, I want some application that tracks the number of times I use each icon on my dock. That way I can periodically go through and clear out the icons that I never use.

I also think it would be interesting if there were an application that tracked the number of times I used each key on the keyboard. I'm sure I'd end up with a massively disproportionate use of COMMAND+X and COMMAND+V. Not to mention WSAD.

Do these applications exist for OSX?
