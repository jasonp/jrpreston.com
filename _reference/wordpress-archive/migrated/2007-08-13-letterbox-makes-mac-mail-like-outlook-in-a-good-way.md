One of the things that I had a hard time letting go of when I switched over to using Mac Mail instead of Outlook - which is basically all I've used for years - was the horizontal layout that you get in Outlook.

I was poking around Google this morning looking for a plugin to do something else entirely in Mail (which I still haven't found, and might try to make myself), when I stumbled across this plugin called [Letterbox](http://harnly.net/software/letterbox/), made by Aaron Harnly, and if you download the latest version of the plugin and run the installer, you'll end up with a nice widescreen split-crazy-cool mail window that looks like this:

[Image: mail wide]

Enjoy!
