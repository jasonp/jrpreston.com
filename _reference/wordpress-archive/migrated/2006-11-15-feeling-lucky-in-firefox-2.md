I love Firefox 2.0, I think it's great. Almost everything they changed has been for the better.  
  
Almost.  
  
In the old versions of Firefox, I could type something into the address bar and, if it wasn't an address, it would do an "I'm feeling lucky" search on Google, and take me to the result.  
  
Now, if I try the same thing, it just tells me I haven't put in a valid URL. This is <em>so annoying</em> to me because I've got myself into the habit of using the "I'm Feeling Lucky" for a lot of keywords that are easier than web addresses.  
  
I'm sure there's a way to re-enable this feature somehow. But why is it so hard to find?
