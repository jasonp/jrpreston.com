\[ **Update**: I got the font working all over the page with a stunning combination of teaching myself CSS through web tutorials and deals with the devil. But now that it's up and running, I'm not sure what I think about it. \]

\------  
I set about this morning to reset the font on my website from whatever the default setup with K2 was over to "Trebuchet MS," which I think is a better font for blogging, at least.

I think it's also the font used in Typepad, but I'm not sure about that because I don't know how to check.

The problem, however, is that I can change everything but the main text of my post. This is very frustrating.

Until I figure this out, my menu bar, my sidebar, and my post headers will all have the new font. The things I have written will not. The only way I can get the font to show up in all the text seems to make the rest of my stylesheet irrelevant and shrink the font size to unreadable smallness.

Needless to say, this is supremely annoying.
