I'm a huge Star Wars fan. I have been since I was about 10 and I first saw the movies. But the things is, I'm really a huge fan of the original theatrical release of each movie - not the special edition.

So it was with great reluctance that I shelled out the $50 for Lucas's boxed set of Star Wars DVDs when they first came out.

Lucas insisted that this was *the* version of the movies, and that he wasn't going to go releasing any other riff raff, so either take 'em or don't. Well I took 'em. It's a lot better than not having them.

And yesterday I found the original theatrical release versions at Target. Sure, they're not in a boxed set, but all three movies were there. So now I have three copies of each Star Wars movie, because there's the special edition box set, and then the new copies which come each with one disk of the special edition and one disk of the original theatrical release.

Lucas is a bastard, but there's really nothing I can do about it.
