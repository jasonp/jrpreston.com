Ballmer of Microsoft says that [Google wants special treatment in IE7](http://news.com.com/2100-1032_3-6071433.html?part=rss&tag=6071433&subj=news).

Frankly, I'm with MS on this one - currently, when people upgrade from IE6 to IE6, the program won't mess with your default search settings. Google is trying to call that "monopolistic" because it doesn't prompt the user to select a new default search engine.

The irony is of course that shoving a "list of search engines ranked by usage" into people's faces instead of simply carrying a preference over is just a dirty trick for more traffic.
