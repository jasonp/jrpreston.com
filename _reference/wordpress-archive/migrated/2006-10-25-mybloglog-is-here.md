I signed up for this service ages ago after I saw it show up on Fred Wilson's blog, and installed the script and set up the tracking for Flicker Gaming. Since I didn't particularly care as much about tracking outbound clicks on this site, I never bothered setting it up here.

But now that the MyBlogLog community (and excellent idea) is growing, I thought I'd add the widget to the sidebar and the script to my page.

For some time now I've been really interested in discoverability (or findability as I've heard it from Dave Taylor), and how blogs make a non-community community. Although "we bloggers" like to talk about how we're one big happy family, the fact of the matter is the only way to link together is with in-post links, most of which go ignored.

MyBlogLog is capable of finally changing that - of linking blogs together through frequent readers.

I'm set to be embarrassed at the size of my readership (tiny, I'm sure), but with any luck people will bounce around the internet and eventually show up here.
