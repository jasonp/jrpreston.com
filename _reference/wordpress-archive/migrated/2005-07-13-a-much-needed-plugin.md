It occured to me that I spend a lot of unnecessary time typing out all the html tags for every one of those links you find in my entries. I'm not really aware of a better way to do it. But I *did* think of a really cool idea for a WordPress plugin. I just don't have the coding knowledge to do it.

I want to see someone make a Google-Link plugin for WordPress.

It works like this: you can use a quick tag like "" or something that's not being used to mark a phrase. When you post the entry, the plugin grabs everything in the tag, and runs a google "I'm feeling lucky" search for that phrase. Then it replaces the phrase with a link to that site--voila! A link without the address!

A bit risky sometimes, I guess, but if you're sure of what you're linking to--say, "Microsoft," there's really no need to worry.
