# Reference material

Source material for building the new site. Not part of the Astro build — Astro only processes `src/` and `public/`, so this folder is ignored by the build but tracked in git.

- `current-site/` — the live jrpreston.com as of April 2026 (single-page HTML + CSS)
- `bio/` — various bio drafts and the long markdown bio
- `claude-2025/` — the reimagined-resume experiment, braindump, and Profile PDF
- `drafts/` — unpublished essays from `writing/drafts/` (grit theory of investing, see_matrix, etc.)
- `wordpress-archive/` — the 2011 WordPress SQL dump (~1,781 published posts across two blog tables), to be parsed in M5
