At the last of the last of today's sessions, the Microsoft people up on the stage pointed out that MSN Live search has a new macro-making ability.

You can find the cool looking features at:

[http://search.live.com/macros/](http://search.live.com/macros/)

Basically it's an extremely user-friendly setup for making a search "macro," or a setup wherein you set a special MSN search box that searches only a specific list of sites (up to thirty different sites you enter in a box).

I can imagine it'd be useful, for example, if you had a number of blogs you read regularly, and you wanted to search within them for something that you know you read somewhere, but couldn't remember where.
