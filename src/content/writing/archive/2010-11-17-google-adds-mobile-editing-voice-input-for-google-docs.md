[Google adds mobile editing, voice input for Google Docs](http://techflash.com/seattle/2010/11/google-adds-mobile-editing-voice.html)

> Google this morning announced mobile editing for Google Docs, to be rolled out in the coming days for devices running Android (version 2.2) and Apple iOS (version 3.0 and higher). The feature makes it possible to use a mobile browser to edit documents stored online, and synchronized to a PC web browser.
