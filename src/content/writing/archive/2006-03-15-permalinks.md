Back in July or August, when I was first setting up WordPress on this site, I decided to try and arrange my permalinks so that the structure made sense.  
  
That is, I wanted the links to be things like: /2005/september/my\_example\_post  
  
instead of: /?p=405, or whatever number nonsense it is now.  
  
But now I think it's too late to do that, because I don't want to destroy all links I've accumulated. So I can now imagine the day when my links are just going to be a string of long numbers.  
  
I guess the advantage is that it's a shorter address, albeit hard to identify. Oh well. So goes technology.
